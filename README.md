# CS2 Game Item Learning Site

CS2 战术道具学习网站（UTILITY LAB）——React + Vite + Tailwind CSS v4 构建，源自 Figma Make。

- 地图道具教学：Mirage / Inferno / Nuke / Dust2 / Anubis / Ancient
- T 方 / CT 方道具列表，按烟雾、闪光、燃烧、手雷分类
- 每个道具含站位、瞄点、轨迹、效果图四格教学

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并通过 GitHub Pages 发布。
